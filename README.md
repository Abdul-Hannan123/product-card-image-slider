# 🛍️ Product Card with Image Slider

A modern and responsive **Product Details Card** built using **HTML, CSS, and JavaScript**.

This project displays product information along with an interactive image slider. The product image can be changed by clicking the **image navigation dots**.

---

## ✨ Features

- 🛍️ **Modern product details card**
- 🖼️ **Three product images**
- 🔘 **Interactive image navigation dots**
- 🖱️ Click on the dots to **change the product image**
- 🎨 Clean and modern UI
- 📱 Responsive design
- 💰 Displays product price and discount
- 👕 Product size selection
- 🎨 Product color selection
- 🔢 Quantity display
- 🛒 **Buy Now** button
- ⚡ Built using Vanilla JavaScript
- 🚫 No external frameworks or libraries required

---

## 📸 Project Preview

The project contains a product card with:

- Product image
- Product name
- Product price
- Discount information
- Product description
- Available sizes
- Available colors
- Quantity
- Buy Now button

On the left side, three **navigation dots** are displayed.

Clicking on a dot changes the displayed product image.

---

## ⚙️ How It Works

The project uses **JavaScript click events** to change the product image.

There are three product images available.

When the user clicks on one of the navigation dots:

1. JavaScript detects which dot was clicked.
2. The corresponding product image is selected.
3. The current image is replaced with the selected image.
4. The active dot is updated to indicate the selected image.
